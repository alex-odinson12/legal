# Правовые документы приложений

Статический сайт на GitHub Pages. Адрес документа устроен так:

    /legal/<приложение>/<платформа>/<язык>/<документ>/

Смысл схемы: адрес, однажды напечатанный в карточке магазина и зашитый в выпущенную сборку,
менять нельзя – её пользователи продолжат ходить именно туда. Новый язык, вторая платформа
или переименование приложения ДОБАВЛЯЮТ страницы, а не переписывают существующие.
Идентификатор приложения в пути (`cardscan`) намеренно не совпадает с названием в сторе:
название может смениться, путь – нет.

Условия использования отдельной страницей обычно не издаются: приложения портфеля идут
на стандартной лицензии Apple, как LegitCheck iOS. Исключение – Motivation Quotes (`mq`): у него
свои условия подписки (`mq/ios/<en|ru>/terms/`), на них ведёт ссылка внутри приложения.

Документы других приложений опубликованы раньше и остаются на своих адресах:
`peoplefinder-legal-ru`, `legitcheck-legal-ru-android`.
